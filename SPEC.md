# VIRTUAL WORLD ARCHIVE
Virtual World Archive is designed to extend the Internet Archive's existing support for running games in browser-based emulators by supporting uploading and configuring server assets and preserving them in a functional supports uploading servers as well as clients 

## THE STARTING POINT
The UI starts as an extension of the existing Archive Software category, with browser-based emulated game client being uploadable and mangaeable.
https://archive.org/details/emulation

## THE NEW SERVER LIBRARY
The server library allows people to upload and manage game servers for online worlds to facilitate multiplayer gameplay by users running clients from within other Archived emulations or downloaded versions with a network shim to direct their apps/games to connect to the Archive servers.

## WORLD ARCHIVAL TOOLKIT
For game developers trying to package their servers to run within the World Archival containers, the Virtual World Archival Toolkit.

## WORLD ARCHIVAL EXAMPLE PROJECTS
World Archival Example Projects are demo projects in various game engines showing a simple multiplayer virtual world client and server implementation allowing it to be archived cleanly on the Virtual World Archive container system.

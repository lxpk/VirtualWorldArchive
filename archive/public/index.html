Preserved multiplayer worlds. Each world keeps its game server and database running in a container, so archived clients can still meet each other.

Game server A .zip or .tar.gz containing a Dockerfile. The server listens on $PORT; a Postgres database is passed in as $DATABASE_URL. See the toolkit.
Web client A .zip of a browser build with an index.html: a Unity WebGL build, a web export, or an emulator page. It is served at /clients/<id>/ and can reach its server at /play/<server-id>.
